CAMPUSVOICE BACKEND-READY BUILD

This package keeps the approved frontend and adds the first real backend/database layer for Supabase.

Open in VS Code:
1. js/supabase-config.js
2. database/supabase_schema.sql
3. BACKEND_SETUP.md

IMPORTANT:
- Do not put Supabase service_role/secret keys in frontend files.
- Run the SQL in Supabase SQL Editor first.
- Then add only the Project URL and Publishable key to js/supabase-config.js.
- Student signup and login are wired to Supabase when configured.
